# Fontes

Documento cru vai aqui: print do Mercado Livre, tabela de taxas, PDF de fornecedor,
export de planilha, foto de produto.

## Como usar

1. Jogue o arquivo nesta pasta.
2. Diga na conversa o que ele é e o que você quer que eu tire dele.
3. Se o que sair dali virar decisão (um custo novo, uma taxa que mudou, um veredito
   de produto), eu gravo no arquivo certo de `docs/3d/` — a fonte fica aqui só como
   comprovante.

## Formatos que eu leio direto

Markdown, texto, CSV, JSON, HTML, PDF, PNG e JPG.

## Nomeie assim

`AAAA-MM-DD-assunto.ext` — por exemplo `2026-09-18-taxas-ml-categoria-casa.pdf`.
A data importa: taxa de marketplace envelhece rápido, e eu preciso saber se o que
está em `02-regras-mercado-livre.md` é mais novo ou mais velho que a fonte.
