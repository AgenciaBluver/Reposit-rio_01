# Glossário — o vocabulário aprovado

Só estes termos. Nada de "caixa", "desembolso", "desgaste", "lucro após desgaste"
ou qualquer coisa inventada para a ocasião.

| Termo | O que é |
|---|---|
| **Custo do produto** | Material + eletricidade + máquina + peças perdidas + insumos + embalagem |
| **Custos da venda** | Comissão + tarifa fixa + frete + logística + imposto + publicidade |
| **Lucro por produto** | Preço menos os dois acima |
| **Margem de lucro** | Lucro ÷ preço de venda |
| **Markup** | Preço ÷ custo do produto |
| **Lucro por hora de impressora** | Lucro ÷ horas de impressão. **A métrica que ordena tudo** |
| **Preço mínimo** | Preço em que o lucro é zero |
| **Tarifa fixa** | O valor fixo por venda que o ML cobra abaixo de R$ 79 |

## Linhas do custo do produto

| Linha | Conta |
|---|---|
| Material | (preço do kg ÷ 1000) × gramas × 1,05 |
| Eletricidade | 0,120 kW × horas × tarifa do kWh |
| Máquina | R$/hora × horas |
| Peças perdidas | (material + eletricidade + máquina) × (falha ÷ (1 − falha)) |
| Insumos | por peça |
| Embalagem | por anúncio |
